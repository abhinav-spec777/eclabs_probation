# E-Commerce Sales & Profit Analytics Dashboard

## 📊 Project Overview

An interactive E-Commerce Sales & Profit Analytics Dashboard developed using Microsoft Power BI.

The dashboard transforms transactional sales data into meaningful business insights across products, categories, regions and time.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## 📈 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Average Order Value

## 🔍 Dashboard Features

- Interactive filters and slicers
- Sales and profit trend analysis
- Product performance analysis
- Category analysis
- Regional analysis
- Interactive visualizations
- Drill-through analysis
- Dynamic KPIs

## 📊 Dataset

The dataset contains 3,500 e-commerce transactions covering:

- 10 Products
- 3 Categories
- 4 Regions
- 2022–2024
